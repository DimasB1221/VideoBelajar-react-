## Tech Stack

This project is built using modern, production-ready technologies to ensure performance, scalability, and maintainability.

### Frontend

- **React** – Component-based JavaScript library for building scalable and maintainable user interfaces
- **Vite** – Next-generation frontend tooling for fast development and optimized production builds
- **TypeScript** – Static typing to improve code quality and long-term maintainability
- **Tailwind CSS** – Utility-first CSS framework for consistent, responsive, and scalable UI development

### State & Data Management

- **TanStack Query (React Query)** – Server-state management with efficient caching, background synchronization, and request deduplication
- **Axios** – Promise-based HTTP client for API communication

### Backend & Database

- **Supabase** – Backend-as-a-Service providing authentication, PostgreSQL database, and storage
- **PostgreSQL** – Relational database for reliable and structured data management

### Tooling & Deployment

- **Vercel** – Cloud platform for deploying and hosting modern frontend applications
- **Git & GitHub** – Version control and collaborative development

### Development Principles

- **Clean Code Principles** – Focus on readability, maintainability, and separation of concerns
- **Performance Optimization** – Optimized rendering, efficient data fetching, and caching strategies
- **Robust Error Handling** – Predictable and consistent error handling across the application

## Tech Stack

Proyek ini dibangun menggunakan teknologi modern yang siap untuk lingkungan produksi guna memastikan performa, skalabilitas, dan kemudahan pemeliharaan.

### Frontend

- **React** – Library JavaScript berbasis komponen untuk membangun antarmuka pengguna yang skalabel dan mudah dipelihara
- **Vite** – Tooling frontend generasi terbaru untuk pengembangan yang cepat dan build produksi yang optimal
- **TypeScript** – Static typing untuk meningkatkan kualitas kode dan maintainability jangka panjang
- **Tailwind CSS** – Framework CSS utility-first untuk pengembangan UI yang konsisten, responsif, dan skalabel

### State & Manajemen Data

- **TanStack Query (React Query)** – Manajemen server-state dengan caching yang efisien, sinkronisasi background, dan deduplikasi request
- **Axios** – HTTP client berbasis Promise untuk komunikasi API

### Backend & Database

- **Supabase** – Backend-as-a-Service yang menyediakan autentikasi, database PostgreSQL, dan storage
- **PostgreSQL** – Database relasional untuk pengelolaan data yang terstruktur dan andal

### Tooling & Deployment

- **Vercel** – Platform cloud untuk deployment dan hosting aplikasi frontend modern
- **Git & GitHub** – Version control dan kolaborasi pengembangan

### Prinsip Pengembangan

- **Clean Code Principles** – Fokus pada keterbacaan, kemudahan pemeliharaan, dan pemisahan tanggung jawab
- **Optimasi Performa** – Rendering yang optimal, pengambilan data yang efisien, dan strategi caching
- **Penanganan Error yang Andal** – Manajemen error yang konsisten dan dapat diprediksi di seluruh aplikasi
